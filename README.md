# Зум камеры и демонстрации

Интерактивный прототип: [открыть](https://doorotar9-png.github.io/participant-zoom-preview/#preset=sixteen-share&size=desktop&toolbar=v6&entry=button).

Отдельный эксперимент с увеличением изображения участника и демонстрации экрана. Содержит восемь сценариев для звонков1на1,5и16человек; два варианта входа в зум переключаются справа. В варианте «Через „Увеличить“» доступны только масштаб и перемещение, в прежнем варианте — также временные пометки на демонстрации.

Это статический макет с локальными фикстурами, без подключения к реальному звонку и серверным функциям. Рабочая версия проверяется в настольном браузере с мышью; полноценная поддержка мобильных жестов и fullscreen не заявляется.

Этот репозиторий содержит только подготовленную сборку. Разработка и документация проекта хранятся отдельно. Обновления публикуются в main; GitHub Pages раздаёт содержимое корня. Основной макет звонка находится по [прежнему адресу](https://doorotar9-png.github.io/video-call-preview/).
